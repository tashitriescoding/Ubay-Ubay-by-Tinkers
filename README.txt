Ubay-Ubay artist call site (raffle look, main-site content)

Open index.html in a browser. No build step.
- index.html / style.css / script.js : the new one-page site
- assets/ : logos, sample pins, Agrandir fonts (from the main site)
- artist-signup/ : the original main site's sign-up page, unchanged, so the
  "Read the letter & sign up" button still works (same Google Apps Script backend).
  Its upload.html / admin.html pages were not copied; add them from the original if needed.
Headings use Amatic SC from Google Fonts, so they need an internet connection to look right.
